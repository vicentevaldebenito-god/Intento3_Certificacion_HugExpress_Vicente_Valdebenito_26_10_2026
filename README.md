# HugExpress

## Descripción

**HugExpress** es una plataforma web orientada al seguimiento, gestión y cotización de servicios de paquetería y envíos exprés. El sitio ofrece una interfaz intuitiva que permite a los usuarios consultar tarifas, realizar el seguimiento de sus envíos en tiempo real y explorar los distintos servicios logísticos disponibles.

---

## Características Principales

- **Navegación y Panel Principal:** Barra de navegación accesible con logotipo institucional, enlaces directos a las secciones clave, área de contacto y gestión de usuario.
- **Módulo de Cotización y Envío:** Formulario interactivo para estimar costos y tiempos de entrega según el destino y dimensiones del paquete.
- **Rastreo en Tiempo Real:** Sistema de seguimiento de paquetes (*tracking*) mediante código de envío.
- **Catálogo de Servicios:** Sección informativa detallada con las distintas modalidades de entrega (Exprés, Estándar, Internacional).
